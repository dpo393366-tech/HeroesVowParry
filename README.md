# 입지전 — 무투·설전 패링 2.0.0

기존 턴제 전투에서 **섬광·효과음에 맞춰 우클릭 또는 Q를 누르면 공격을 패링**합니다. 연타는 타격별로 판정하며, 적에게 패링을 누적하면 그로기를 유발합니다.

## 설치와 사용

1. **HeroesVowParry-2.0.0.zip**을 받아 전체 압축을 풉니다. [다운로드](https://github.com/dpo393366-tech/HeroesVowParry/releases/tag/v2.0.0)
2. 게임을 종료하고 **Install.bat → 1 Install → 게임 폴더 선택**.
3. 게임의 **MOD 불러오기 → 무투·설전 패링**에서 ON/OFF, **F11**에서 세부 설정.

BepInEx가 없으면 자동 설치하며, 기존 IL2CPP 로더와 설정은 유지합니다. 설치 후에는 게임 시작 시 자동 업데이트됩니다. 인터넷 연결에 실패하면 기존 설치본으로 실행합니다.

## 상대의 강함은 어떻게 판단하나요?

| 평가 항목 | 무투 | 설전 |
| --- | --- | --- |
| 기본 전투 능력 | 무투 공격력·방어력, 지력 | 설전 공격력·방어력 |
| 혼 | 무혼 + 지혼 | 지혼 |
| 장착 비급 | 무투 비급의 위력·희귀도 | 설전 비급의 위력·희귀도 |
| 행동 효율 | 비급의 행동력 소모, 행동력 회복량, 패 뽑기 수 | 비급의 행동력 소모, 행동력 회복량 |

이 항목들을 종합해 **공격자와 실제 방어자 한 쌍씩** 비교합니다. 상대적으로 강한 적일수록 공격 동작이 빨라지고 패링 인정 시간이 짧아지며, 적의 자동 패링 확률도 같은 평가를 따릅니다. 한계값은 F11에서 조절합니다.

평가는 **전투 시작 시 고정**됩니다. 주인공·동행장수마다 상대와의 차이를 따로 적용하며, 체력·진기·군혼과 전투 중 뽑힌 패는 평가에 넣지 않습니다.

## 회피 제한은 어떤 기능인가요?

회피만 반복해서 공격을 전부 피하는 상황을 줄입니다. 무투의 아군·적군·짐승에 적용하며, 패링과 별도로 켜고 끌 수 있습니다.

- **회피 확률 상한 — 기본 70%:** 원래 회피율이 90%여도 70%까지만 허용합니다. 원래 30%라면 그대로 30%입니다. F11에서 상한을 **0~70%**로 설정하며, 0%면 회피할 수 없습니다.
- **연속 회피 제한 — 기본 4회:** 한 캐릭터가 4번 연속 회피하면 **다음 공격은 회피할 수 없습니다.** 중간에 맞으면 횟수가 초기화됩니다. F11에서 **1~10회**로 조절합니다. 패링 판정은 별개입니다.

## F11에서 조절할 수 있는 것

패링 입력 시간·사전 입력·연타 방어 유지, 단타 공격 배속, 적 자동 패링 확률 상한, 강적의 최대 공격 배속·최소 패링 시간, 그로기 횟수·피해 배율, 회피 제한을 조절합니다.

## 제거

게임 종료 후 **Install.bat → 2 Remove**. 패링·회피 제한·자동 업데이트를 제거하며 설정과 백업은 남깁니다.
