# Heroes' Vow — 무투·설전 패링

무투·설전의 실시간 패링을 단독 모드로 제공합니다. 기존 턴제 진행을 유지하며, 우클릭 또는 **Q**로 공격을 막습니다.

## 설치

1. [Releases](https://github.com/dpo393366-tech/HeroesVowParry/releases/latest)에서 `HeroesVowParry-2.1.0.zip`을 받습니다.
2. ZIP 전체를 압축 해제하고 게임을 종료합니다.
3. `Install.bat` 실행 → `1 Install` → 게임 폴더 선택. 설치 위치는 특정 드라이브에 고정되지 않습니다.
4. 게임 실행 → **MOD 불러오기** → 목록 맨 아래 **무투·설전 패링** 체크로 ON/OFF.

**환경:** Windows x64, 입지전 IL2CPP. 게임 버전 번호나 데이터 해시 일치로 설치를 막지 않습니다. BepInEx가 없는 깨끗한 환경에는 동봉한 공식 BepInEx 6 IL2CPP 로더를 자동 설치합니다. 기존 IL2CPP 로더가 있으면 버전 차이로 거부하거나 덮어쓰지 않고 그대로 사용합니다.

다른 종류의 로더/주입기가 이미 있거나 설치가 불완전하면 기존 파일을 보존하고 모드 DLL만 설치하며 안내를 표시합니다. BepInEx 5 Mono처럼 실행 방식이 다른 로더까지 자동 변환하지는 않습니다. 이 경우 설치 완료가 로더 호환 보장을 뜻하지 않습니다. 게임 본체는 포함하지 않습니다.

## 사용

- **우클릭 / Q:** 패링. 두 입력은 동일한 판정·대기 시간을 사용합니다.
- **F11:** 단타 공격 배속, 섬광·소리 후 입력 시간, 사전 가드 인정, 연타 방어 유지, 적 자동 패링 상한, 그로기 횟수·피해 배율, 강적 공격 배속·패링 시간 조절.
- **F11 회피 제한:** 별도 ON/OFF, 최대 회피 확률 0~70%, 연속 회피 허용 횟수 1~10회. 기본값은 70%·4회이며 중간에 피격되면 연속 횟수가 초기화됩니다. 아군·적군·짐승의 무투 회피에 적용합니다. 기본적으로 설전 회피를 새로 만들지는 않습니다.
- **MOD 매니저 체크:** 선택 즉시 저장. 전투 밖에서는 바로 전환하며, 전투 중 변경은 진행 중인 피해 처리가 끝나도록 전투 종료 후 적용합니다.
- OFF에서도 MOD 매니저 항목과 F11 설정은 남습니다. 다시 ON 하면 패링 기능이 재개됩니다.
- 회피 제한은 패링 ON/OFF와 별도로 작동합니다. 기존 통합 F11이 있으면 `회피 제한` 탭을 사용하고, 없으면 자체 F11의 하단에서 조정합니다.

패링 입력·예고·성공 이펙트·효과음, 자동 패링, 연타 판정, 그로기와 게이지, 강함 차이 보정 및 기존 전투 복구 처리를 포함합니다. 적 체력·공격력·차례 배율, 야외 등급·보상, 동행 인원 확대는 포함하지 않습니다.

## 기존 패링 사용자의 교체

기존 `DuelCounters.dll` 및 `DodgeLimit.dll`과 같은 플러그인 ID를 사용합니다. 설치기는 이전 버전의 해시를 제한하지 않고 두 모듈을 `BepInEx/disabled-mods/ParryBackup-*`에 백업한 뒤 각각 하나로 교체합니다. 이름이 바뀐 같은 어셈블리도 확인합니다. 다른 플러그인·설정·로더는 교체하지 않습니다. 연결 폴더는 건드리지 않고 안내하므로 연결 폴더 속에 같은 모드가 있다면 중복 여부를 따로 확인하세요.

기존 설정 파일 `BepInEx/config/local.heroesvow.counters.cfg`와 `local.heroesvow.dodgelimit.cfg`는 유지합니다. `[Module] Enabled`가 패링 ON/OFF이고, 회피 제한은 별도 설정입니다. 처음 설치하면 둘 다 ON입니다. 기존 통합 F11 창이 있으면 해당 창에 연결하며, 없으면 자체 F11 창을 사용합니다.

게임 업데이트로 실제 함수 구조가 달라 초기화가 실패하면 부분 적용된 패링 패치를 해제하고 F11/로그에 원인을 알립니다. 일부 MOD 메뉴 진입 함수가 없어도 남아 있는 진입 경로를 사용합니다. 데이터 버전 제한을 없앤 것이 미래의 모든 게임 업데이트에 대한 호환 보장을 뜻하지는 않습니다.

이후 구버전 통합 설치기로 패링 항목을 다시 설치하면 DLL이 구버전으로 돌아갈 수 있으므로 독립판 설치기를 사용하세요.

## 제거

게임 종료 → `Install.bat` → `2 Remove`. 패링과 회피 제한 DLL을 백업 폴더로 옮겨 제거합니다. 설정·로더·백업은 보존하며, 이전 모드를 자동 복구하지 않습니다.

## 소스 빌드

`.NET SDK`, `.NET 6 reference pack`, 사용자가 소유한 게임과 BepInEx의 참조 DLL이 필요합니다.

```powershell
./build.ps1 -GameDir '게임 설치 폴더'
```

검증 범위는 [VALIDATION.md](VALIDATION.md), 변경 사항은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

소스와 설치 파일에 게임 실행 파일, 모델, 세이브, 개인 설정은 포함되지 않습니다. 사운드 리소스의 권리는 각 원저작자에게 있습니다. 자동 설치용 로더의 출처는 [THIRD_PARTY.md](THIRD_PARTY.md)에 기록했습니다.
