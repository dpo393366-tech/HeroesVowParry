# Heroes' Vow — 무투·설전 패링

무투·설전의 실시간 패링을 단독 모드로 제공합니다. 기존 턴제 진행을 유지하며, 우클릭 또는 **Q**로 공격을 막습니다.

## 설치

1. [Releases](https://github.com/dpo393366-tech/HeroesVowParry/releases/latest)에서 `HeroesVowParry-2.0.0.zip`을 받습니다.
2. ZIP 전체를 압축 해제하고 게임을 종료합니다.
3. `Install.bat` 실행 → `1 Install` → 게임 폴더 선택. 설치 위치는 특정 드라이브에 고정되지 않습니다.
4. 게임 실행 → **MOD 불러오기** → 목록 맨 아래 **무투·설전 패링** 체크로 ON/OFF.

**필수 환경:** Windows, 입지전 1.0.13, BepInEx 6 IL2CPP. 게임 본체와 BepInEx 로더는 패키지에 포함하지 않습니다. 설치기는 확인된 게임 데이터 버전만 허용합니다.

## 사용

- **우클릭 / Q:** 패링. 두 입력은 동일한 판정·대기 시간을 사용합니다.
- **F11:** 단타 공격 배속, 섬광·소리 후 입력 시간, 사전 가드 인정, 연타 방어 유지, 적 자동 패링 상한, 그로기 횟수·피해 배율, 강적 공격 배속·패링 시간 조절.
- **MOD 매니저 체크:** 선택 즉시 저장. 전투 밖에서는 바로 전환하며, 전투 중 변경은 진행 중인 피해 처리가 끝나도록 전투 종료 후 적용합니다.
- OFF에서도 MOD 매니저 항목과 F11 설정은 남습니다. 다시 ON 하면 패링 기능이 재개됩니다.

패링 입력·예고·성공 이펙트·효과음, 자동 패링, 연타 판정, 그로기와 게이지, 강함 차이 보정 및 기존 전투 복구 처리를 포함합니다. 적 체력·공격력·차례 배율, 야외 등급·보상, 동행 인원 확대는 포함하지 않습니다.

## 기존 패링 사용자의 교체

기존 `DuelCounters.dll`과 같은 플러그인 ID를 사용합니다. 설치기는 알려진 이전 DLL을 `BepInEx/disabled-mods/ParryBackup-*`에 백업하고 하나의 DLL로 교체합니다. 이름이 바뀐 같은 어셈블리도 확인합니다. 확인되지 않은 DLL은 덮어쓰지 않습니다.

기존 설정 파일 `BepInEx/config/local.heroesvow.counters.cfg`는 유지합니다. `[Module] Enabled`가 전체 ON/OFF입니다. 처음 설치하면 ON입니다. 기존 통합 F11 창이 있으면 해당 창의 패링 항목에 연결하며, 없으면 자체 F11 창을 사용합니다.

이후 구버전 통합 설치기로 패링 항목을 다시 설치하면 DLL이 구버전으로 돌아갈 수 있으므로 독립판 설치기를 사용하세요.

## 제거

게임 종료 → `Install.bat` → `2 Remove`. 이 버전의 패링 DLL만 제거합니다. 설정과 백업은 보존하며, 백업한 이전 패링을 자동 복구하지 않습니다.

## 소스 빌드

`.NET SDK`, `.NET 6 reference pack`, 사용자가 소유한 게임과 BepInEx의 참조 DLL이 필요합니다.

```powershell
./build.ps1 -GameDir '게임 설치 폴더'
```

검증 범위는 [VALIDATION.md](VALIDATION.md), 변경 사항은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

소스와 설치 파일에 게임 실행 파일, 모델, 세이브, 개인 설정은 포함되지 않습니다. 사운드 리소스의 권리는 각 원저작자에게 있습니다.
