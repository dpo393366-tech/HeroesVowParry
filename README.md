# 입지전 — 무투·설전 패링 2.0.0

기존 턴제 전투에서 **섬광·효과음에 맞춰 우클릭 또는 Q를 누르면 공격을 패링**합니다. 연타는 타격별로 판정하며, 적에게 패링을 누적하면 그로기를 유발합니다.

## 설치와 사용

1. **HeroesVowParry-2.0.0.zip**을 받아 전체 압축을 풉니다. [다운로드](https://github.com/dpo393366-tech/HeroesVowParry/releases/tag/v2.0.0)
2. 게임을 종료하고 **Install.bat → 1 Install → 게임 폴더 선택**.
3. 게임의 **MOD 불러오기 → 무투·설전 패링**에서 ON/OFF, **F11**에서 세부 설정.

BepInEx가 없으면 자동 설치하며, 기존 IL2CPP 로더와 설정은 유지합니다. 설치 후에는 게임 시작 시 자동 업데이트됩니다. 인터넷 연결에 실패하면 기존 설치본으로 실행합니다.

## 패링과 연타

- **우클릭 / Q:** 공격 예고의 섬광·소리에 맞춰 누르면 해당 타격의 피해와 공격에 붙은 띄우기·밀쳐내기 등의 효과를 막습니다. 성공만으로 상대 턴을 즉시 끝내지는 않습니다.
- **조작 대상:** 주인공이 참전한 전투에서는 공격받는 주인공·동행·아군 장수를 방어할 수 있습니다. AUTO 중에도 직접 입력할 수 있으며, 적·아군의 확률형 자동 패링도 작동합니다.
- **연타:** 각 타격을 따로 막습니다. 한 번의 가드로 짧게 이어지는 타격도 방어할 수 있고, 놓친 타격의 피해는 받습니다. 원래 마지막에 피해를 몰아 주는 기술은 막지 못한 몫을 마지막에 합산합니다.
- **밀려남:** 무투에서 같은 턴의 카드 공격 3회를 연속으로 패링당하면 밀려나는 반응이 발생합니다. 연타 한 카드는 1회로 세며, 이 횟수는 턴 종료 시 초기화됩니다. 아래 그로기 누적과는 별도입니다.
- **성공 보상:** 기본적으로 성공 2회마다 행동력 1을 회복합니다(상한까지). 체력·진기는 회복하지 않습니다.
- **입력 여유:** 기본 인정 시간은 예고 후 0.35초, 미리 누르기는 0.2초, 연타 방어 유지는 0.25초입니다. 실패 시 0.6초 대기, 성공 시 즉시 다음 패링이 가능합니다. 궁술에는 0.1초의 추가 여유가 있습니다.

행동력 소모 **3 이하 공격은 금빛 섬광**, **4 이상은 붉은·금빛 효과**로 예고합니다. 성공 시 충돌 지점의 스파크와 효과음이 나오며, 일반 패링음은 타격마다 무작위로 재생합니다. 강한 카드와 적의 패링은 별도 효과음을 사용합니다.

## 적 그로기

| 상황 | 동작 |
| --- | --- |
| 적 공격을 패링 | 단타는 누적 +1, 연타는 패링한 타격마다 +0.25. 파란 게이지도 그만큼 감소 |
| 적이 아군에게 실제 피해를 줌 | 공격한 적의 누적량 −1, 최소 0 |
| 누적량 10 도달 | 그로기 발동. 단타 10회 또는 연타 40타 패링에 해당하며 혼합해서 누적. 턴이 끝나도 유지 |
| 화면 표시 | 적 체력바 바로 아래의 파란 바가 줄어들어 소진되면 그로기. 그로기 자세와 별 효과 표시 |
| 그로기 중 | 다음 자기 차례 1회 건너뛰기, 패링·회피 불가, 무적을 포함한 강화 효과 해제·재적용 차단, 받는 피해 1.3배 |
| 다시 행동 가능한 차례가 옴 | 그로기 해제, 누적 0·게이지 복구·피해 배율 정상화. 피해 배율은 중첩되지 않음 |

그로기는 **적에게만** 적용합니다. F11에서 발동 누적량과 피해 배율을 조절합니다. 여러 명이 같은 타격을 패링해도 중복 누적하지 않습니다.

## 상대의 강함은 어떻게 판단하나요?

| 평가 항목 | 무투 | 설전 |
| --- | --- | --- |
| 기본 전투 능력 | 무투 공격력·방어력, 지력 | 설전 공격력·방어력 |
| 혼 | 무혼 + 지혼 | 지혼 |
| 장착 비급 | 무투 비급의 위력·희귀도 | 설전 비급의 위력·희귀도 |
| 행동 효율 | 비급의 행동력 소모, 행동력 회복량, 패 뽑기 수 | 비급의 행동력 소모, 행동력 회복량 |

이 항목들을 종합해 **공격자와 실제 방어자 한 쌍씩** 비교합니다.

- **비슷하거나 약한 적:** 강함 차이에 따른 추가 가속·입력 시간 축소가 없습니다.
- **강한 적:** 격차에 따라 공격 동작이 점차 빨라지고 패링 인정 시간이 짧아집니다. 신규 설치 기본값은 최대 **1.2배 공속**, 최소 **0.25초 인정 시간**입니다. 턴 순서가 아니라 공격 모션에 적용합니다.
- **적의 자동 패링:** 방어하는 적이 공격자보다 강할수록 성공 확률이 높아지며, 설정한 상한(기본 60%)을 넘지 않습니다.

최대 공속·최소 인정 시간을 F11에서 바꾸면 중간 수준의 적도 그 범위에 맞춰 함께 조정됩니다. 단타 공격은 타격 전 동작을 감속하고 후속 동작은 원래 속도로 돌아갑니다. 강함에 따른 공속 보정은 이 공격 배속에 상대 배율로 적용됩니다.

평가는 **전투 시작 시 고정**됩니다. 주인공·동행장수마다 상대와의 차이를 따로 적용하며, 체력·진기·군혼과 전투 중 뽑힌 패는 평가에 넣지 않습니다.

## 회피 제한은 어떤 기능인가요?

회피만 반복해서 공격을 전부 피하는 상황을 줄입니다. 무투의 아군·적군·짐승에 적용하며, 패링과 별도로 켜고 끌 수 있습니다.

- **회피 확률 상한 — 기본 15%:** 원래 회피율이 90%여도 15%까지만 허용합니다. 원래 10%라면 그대로 10%입니다. F11에서 상한을 **0~70%**로 설정하며, 0%면 회피할 수 없습니다.
- **연속 회피 제한 — 기본 4회:** 한 캐릭터가 4번 연속 회피하면 **다음 공격은 회피할 수 없습니다.** 중간에 맞으면 횟수가 초기화됩니다. F11에서 **1~10회**로 조절합니다. 패링 판정은 별개입니다.

## F11에서 조절할 수 있는 것

패링 입력 시간·사전 입력·연타 방어 유지, 단타 공격 배속, 적 자동 패링 확률 상한, 강적의 최대 공격 배속·최소 패링 시간, 그로기 횟수·피해 배율, 예고 이펙트 ON/OFF, 회피 제한을 조절합니다. 위 수치는 신규 설치 기본값이며, 기존 설정이 있으면 그 값을 유지합니다.

### 신규 설치 기본값

| 설정 | 기본값 |
| --- | --- |
| 단타 공격 모션 배속 | 0.8배 |
| 섬광·소리 후 입력 / 사전 입력 | 0.35초 / 0.2초 |
| 가드 1회 연타 방어 유지 | 0.25초 |
| 적 자동 패링 확률 상한 | 60% |
| 그로기 발동 누적량 / 받는 피해 | 10 / 1.3배 |
| 강적 최대 공격 배속 / 최소 패링 시간 | 1.2배 / 0.25초 |
| 패링 예고 이펙트 / 회피 제한 | ON / ON |
| 회피 확률 상한 / 연속 회피 허용 | 15% / 4회 |

게임 종료 후 **Install.bat → 2 Remove**. 패링·회피 제한·자동 업데이트를 제거하며 설정과 백업은 남깁니다.
